# University Registration System

A streamlined web-based university registration system designed to make finding courses, exploring degree requirements, and planning a class schedule easier and more intuitive.

## Overview

This project is a **frontend web application prototype** created using HTML. It focuses on improving the university course registration experience by bringing course discovery, degree-based class searching, advanced class search, and schedule planning into a streamlined interface.

The application includes interactive navigation and functional buttons that demonstrate how a complete university registration system could work.

## Features

### Course Search

* Look up available courses
* Browse course information and options
* Search for classes through the registration interface

### Degree-Based Class Search

* Search for classes based on a student's degree program
* View courses relevant to a specific degree
* Helps students identify courses that apply toward their academic path

### Advanced Class Search

* Provides additional search options for finding specific classes
* Allows students to narrow down courses using different search criteria
* Makes finding specific classes faster and easier

### Calendar & Schedule Planning

* Calendar view for organizing classes
* Weekly calendar view for viewing a student's schedule
* Helps students understand class times and organize their schedules

### Streamlined Interface

* Simplified navigation
* Student-focused registration layout
* Interactive buttons and interface elements
* Designed to reduce unnecessary steps in the registration process

## Current Status

**Frontend Prototype**

The current version focuses on the frontend and user interface. The project demonstrates the intended functionality and user experience through HTML and interactive interface elements.

It does not currently connect to a backend, database, authentication system, or live university course-registration system.

## Getting Started

### Requirements

* [Visual Studio Code](https://code.visualstudio.com/)
* Live Server extension for Visual Studio Code

### Running the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Open the main HTML file.
5. Right-click the HTML file and select **Open with Live Server**.
6. The application will open in your default web browser.

## Project Goals

The goal of this project is to create a more streamlined university registration experience that allows students to:

1. Find courses quickly
2. Search for classes based on their degree
3. Use advanced search options to find specific classes
4. View their schedule using a calendar
5. View their weekly class schedule
6. Navigate the registration process with fewer unnecessary steps
